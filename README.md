**# LP Jewellers

A website for LP Jewellers — a local jewellery shop — built as part of a social internship project supporting local artisans.

## About

LP Jewellers offers handcrafted gold jewellery including rings, necklaces, earrings, and bangles. This site showcases the shop's collections and story, and makes it easy for customers to get in touch.

## Features

- Animated hero section with shimmer effect
- Collections showcase (Rings, Necklaces, Earrings, Bangles)
- About / shop story section
- Photo gallery
- Contact section with call and WhatsApp buttons
- Fully responsive design for mobile and desktop

## Tech

Built with plain HTML, CSS, and JavaScript — no frameworks or build tools required.
